## 0. Project in one paragraph
NEXORA is a SACCO (a "circle") savings and loans app. Backend: Flask + Postgres in `backend/app/**` (tests in `tests/`, run `pytest` from the repo root; migrations in `backend/migrations/versions/`, last is `0023`). Frontend: **React 19 (JavaScript) + Tailwind CSS v4 + Vite** in `frontend/`. Prototype reference: https://claude.ai/artifact/SPDZB7PDFbRt9wDJ3cvxH7 (`docs/frontend/prototype/`, `addmember.js` is the Add a member reference). Screenshots: `docs/frontend/images/`. Human docs: `pdf/NEXORA-Frontend-MASTER.pdf`, `pdf/02-Neo.pdf`. The Master section "Contracts 3b" is the fixed API contract Sam builds against.

## 7. How circles and join codes work (the story to respect)
An **account** (email/password) gives no circle access. A person enters a **circle** only with a one-time 6-digit join code (15 min) issued by the SACCO admin on Add a member, then sets a 4-digit circle PIN and types it to enter. Only platform owners create circles; we never join as staff. Only the SACCO admin holds `member.manage` today (adding it to another role = permission + migration). Staff roles see circle pages only (no My savings, Deposit, Withdraw).
