What it does

Built so the numbers can be trusted.

One ledger, no quiet edits

Every deposit and withdrawal is a ledger row. Balances change only through the ledger, and a reversal is recorded, never deleted.

Two officers, two steps

Larger loans need two approvals, each from a different loans officer. The officer who disburses approved none of the steps.

An audit log you can read

The secretary reads the full trail and cannot change it. The SACCO admin can neither read nor edit it.

Each SACCO sealed off

One SACCO never sees another's records. A suspended SACCO locks until the platform owner reopens it.

How a member gets started

From invitation to first loan.

1

Join with a code

The admin adds your phone number and you get a one-time 6-digit code that lasts 15 minutes.

2

Set your PIN

Pick a 4-digit PIN. It unlocks your session on this device.

3

Save and request

Watch your balance grow and request a loan when you need one.

4

Approve and disburse

Loans officers decide each step, then a finance officer disburses.

Who sees what

Each role gets only its own tools.

Member

Own balance, transactions and loans. Requests and repays loans.

Finance officer

Posts and reverses savings, disburses approved loans, reads reports.

Loans officer

Reviews the loan queue and approves or rejects each step.

Secretary

Reads accounts, loans, members, reports and the audit log. Changes nothing.

SACCO admin

Adds members, assigns roles, posts money and reads reports. Never approves loans.
